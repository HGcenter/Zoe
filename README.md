## Built with

HTML, CSS and vanilla JavaScript. Hosted with GitHub Pages, with a custom domain configured through `CNAME`. No build step or package installation is required. Responsive layouts, separate Chinese and English pages, semantic HTML and downloadable PDF résumés.

To preview locally, open `index.html` or serve this directory with a static web server. Update both language pages and the corresponding PDFs when revising career information.
